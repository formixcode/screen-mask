# screen mask

แผ่นครอบหน้าจอแบบโปร่งใส — ไว้หรี่/กรองส่วนของจอที่สว่างเกิน (เช่นชาร์ต TradingView พื้นขาว)
ลากขอบ/มุมย่อขยายได้เหมือนหน้าต่างโปรแกรมทั่วไป แล้วเลื่อนสไลเดอร์เพื่อปรับความทึบ

## ใช้ยังไง

- **สไลเดอร์** = ความทึบ 0-100% (0 = โปร่งใสสุด ยังเห็นจอข้างหลัง · 100 = ทึบทึบ)
- **ตัวเลข %** มุมซ้ายบน = ค่าปัจจุบัน
- **เส้นขอบเหลือง** รอบหน้าต่าง = ขอบสำหรับจับลาก/ย่อขยาย (ไฮไลต์หัวหมุนก็สีเดียวกัน)
- ปรับขนาด/ย้ายตำแหน่งได้ตามปกติ (title bar ของ Windows, มุมขวาล่าง)

## build

```
cargo build --release
```

ได้ไฟล์ที่ `target\release\screen_mask.exe` (ไฟล์เดียว ~125 KB ไม่ต้องลง runtime อะไรเพิ่ม)

## โครงสร้าง

| ไฟล์ | หน้าที่ |
|---|---|
| `src/main.rs` | ทั้งโปรแกรม — Win32 ล้วน (windows-sys) ไม่มี GUI framework |
| `Cargo.toml` | dependency เดียว: `windows-sys` |

## จุดที่ต้องระวังตอนแก้

- หน้าต่างต้องมี flag `CS_HREDRAW | CS_VREDRAW` ที่ class + สั่ง `InvalidateRect` ใน `WM_SIZE`
  ไม่งั้นลาก/ย่อขยายแล้วเส้นขอบเหลืองจะค้างซ้ำ (Windows ยืดภาพเดิม ไม่วาดใหม่)
- ทั้งหน้าต่างใช้ `WS_EX_LAYERED` + `SetLayeredWindowAttributes(alpha)` → ปุ่ม/ข้อความทั้งหมดจางตาม opacity ด้วยกัน
- ย้ายสไลเดอร์ต้องแก้ `TRACK_X / TRACK_Y / TRACK_H / THUMB` ที่หัวไฟล์
